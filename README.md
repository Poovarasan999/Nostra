# Nostra
🌐 Responsive E-Commerce Website

This project is a fully responsive e-commerce style website built using HTML, CSS, and JavaScript.
The website provides a clean and modern interface for browsing products.

🚀 Features

Responsive design (Mobile, Tablet, Desktop)

Product search functionality

Modern UI layout

Smooth navigation

Product grid display

📂 Pages / Sections

The website contains the following sections:

🏠 Home

🆕 New Arrival

⭐ Most Wanted

🛍️ Collections

📞 Contact

HTML5

CSS3

JavaScript
